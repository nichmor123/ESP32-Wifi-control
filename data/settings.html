How Networking Works:
On boot, the controller will search for the SSID entered below.
- If the network exists, the controller will attempt to connect to it (Client Mode).
- If the password is wrong, it will automatically append a number (e.g., "-1") and broadcast its own Access Point.
- If the network does not exist, the controller will broadcast it as an Access Point (Host Mode).
You can always access the controller via its IP address or by navigating to http://<hostname>.local (e.g. http://esp32controller.local).
