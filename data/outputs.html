Pin Timer Groups & Output Type Mixing Rules (ESCs vs H-Bridges)

1. LEDC Hardware Timer Grouping Principle

The ESP32 hardware LEDC PWM module binds channels to shared internal hardware timers. When mixing ESCs/Servos (50 Hz) and H-Bridges (20 kHz), assign pins in contiguous groups so each group is dedicated to either all 50 Hz outputs or all 20 kHz outputs.

2. Pin Groups for ESP32-WROOM-32

Each group below must be controlled by ALL Servos/ESCs or ALL H-Bridges:

  • Group 1 Pins (GPIO 16, 17, 18, 19): All ESCs/Servos OR up to 2x H-Bridges.
  • Group 2 Pins (GPIO 21, 22, 23, 25): All ESCs/Servos OR up to 2x H-Bridges.
  • Group 3 Pins (GPIO 26, 27, 32, 33): All ESCs/Servos OR up to 2x H-Bridges.

2. Pin Groups for ESP32-S3

Each group below must be controlled by ALL Servos/ESCs or ALL H-Bridges:

  • Group 1 Pins (GPIO 1, 2, 3, 4): All ESCs/Servos OR up to 2x H-Bridges.
  • Group 2 Pins (GPIO 5, 6, 7, 8): All ESCs/Servos OR up to 2x H-Bridges.
  • Group 3 Pins (GPIO 9, 10, 11, 12): All ESCs/Servos OR up to 2x H-Bridges.
  • Group 4 Pins (GPIO 13, 14, 15, 16): All ESCs/Servos OR up to 2x H-Bridges.

4. Hardware & Backend Handling

The C++ backend (OutputManager) automatically isolates the 50 Hz PWM signals (ESCs/Servos) and 20 kHz signals (H-Bridges) onto separate hardware timers. Following the pin groups above guarantees that hardware channels operate without frequency collisions.

Note: Saving output mapping configuration will write your changes to the ESP32 filesystem and automatically restart the controller to reinitialize hardware pins and output PWM signals.
