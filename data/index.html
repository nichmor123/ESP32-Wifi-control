System Overview & Architecture

This controller transforms an ESP32 into a flexible multi-channel radio receiver/controller that accepts real-time commands over WiFi and converts them into physical hardware output signals (PWM, Servos, ESCs, GPIOs, etc.).

Status LED Indicator Guide

The onboard status LED provides clear visual feedback regarding system state:

  • WiFi Running (No Devices Connected): Long double-pulse pattern (1.2s ON, 0.3s OFF, 1.2s ON, 2.0s OFF).
  • Device Connected (WebSocket Active): Heartbeat pulse (0.5s ON, 0.5s OFF).
  • Active Control Stream: Fast double-strobe pulse (80ms ON, 80ms OFF, 80ms ON, 600ms OFF).
  • Auto-Numbering (Unmodified Fresh Board): Flashes N times (e.g., 1 flash, pause, 1 flash, long pause for board -1).
Control & Operation Pages
  • Computer Control: Direct control interface when running from a PC. Connect gamepads (Xbox/F310) or use keyboard shortcuts to send real-time channel streams via WebSocket.
  • Mobile Control: Touch-optimized interface featuring virtual dual joysticks and customizable action buttons for mobile phones or tablets.
Configuration Pages
  • Input Mapping: Assign physical gamepad axes/buttons, keyboard keys, or virtual mobile controls directly to any of the 20 control channels.
  • Input Mixes: Create custom virtual channel mixes combining positive and negative inputs, with configurable deadband, expo, and invert settings on each mix.
  • Output Mapping: Map control channels to physical ESP32 GPIO pins. Supports ESC (Brushed) and Servo output types with customizable input and output ranges.
Monitoring & System Setup
  • Battery Monitor: Set up voltage divider resistor ratios, battery chemistry (LiPo, LiFePO4, Li-ion), cell count, and monitor real-time telemetry voltage.
  • Backup & Restore: Save and export the entire ESP32 configuration package or restore custom configuration backups.
  • Troubleshooting: Perform ping tests, inspect free system memory (RAM heap), view raw connection logs, or trigger ESP32 system reboots.
  • Settings: Configure WiFi Access Point credentials, station mode connections, static IP settings, and system hostname (mDNS).
